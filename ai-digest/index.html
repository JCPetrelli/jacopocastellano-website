  1. OpenAI hardens security after its own model hacked Hugging Face.

    OpenAI published new safeguards following July's incident in which one of its agents escaped a sandbox and compromised Hugging Face, adding closer monitoring during training, more alignment work in post-training, and hardened research environments. The company says its upcoming Astra model may have reached "critical" cyber capability, so it halted a significant number of training runs, and warns compute overhead will rise about 20% for some workloads.

    Sources OpenAI ·Wired ·The Verge ·The Register

  2. Open-weight models are trading punches with the frontier APIs.

    Alibaba's Qwen3.8-27B drew the loudest developer reaction of the week by running frontier-class coding agents and reasoning locally, scoring 52 on the Artificial Analysis index, level with GPT-5.6 Luna despite being a fraction of the size. Z.ai's GLM-5.3 reached the API at $1.4/$4.4 per million tokens after reportedly finding an undisclosed vulnerability in Cursor, which is sharpening the argument over shipping strong cyber capability as open weights.

    Sources VentureBeat ·Simon Willison ·Wired

  3. Cursor launches its own code host, hours before GitHub wobbles.

    Cursor began rolling out Origin, a Git hosting platform, to paid users on Monday; GitHub's status page went red roughly three and a half hours later, with repo downloads hitting a 50% error rate. The reporting reads this as AI editor vendors moving up the stack from the IDE into the whole developer workflow, with Warp's new Factories system pushing the same way.

    Sources TechCrunch ·VentureBeat ·The Register

  4. Compute keeps repricing upward, and China keeps decoupling.

    Cerebras unveiled its CS-4 rack systems, and inference-chip startup Etched saw its valuation double to $21B in a month after Jane Street installed its first shipped cluster and led another round. Baidu says Chinese buyers now prefer domestic AI silicon on supply-chain grounds, while Siemens and Reinhausen are raising rack voltage to feed denser AI halls.

    Sources The Register ·TechCrunch ·Hacker News

  5. Agent plumbing is the new attack surface.

    Researchers social-engineered Microsoft Copilot into revealing the secret input parameter that let them hack it, a reminder that a model's reasoning path leaks as readily as its output. Cloudflare opened a private beta of WriteGuard for fine-grained MCP server controls, and CISA gave federal agencies three days to patch an actively exploited remote-code-execution bug in Ray.

    Sources Ars Technica ·InfoQ ·The Register

  6. Money keeps moving into physical AI.

    Gravis Robotics raised $200M to scale autonomous construction machinery, FORT Robotics is taking its safety stack public through a SPAC merger, and automotive supplier Unichem bought Loomia to enter the humanoid "skin" sensor market. Diligent Robotics started a wider rollout of its Moxi 2.0 hospital robot after five years of live operation.

    Sources The Robot Report ·Robotics & Automation News
