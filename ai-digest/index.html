Everything you need to know about AI

Bookmark this page. The most important things happening in AI, synthesized from dozens of sources into a two-minute read.

Updated every 48 hours Last updated October 10, 2026 · 42 sources · 229 articles · 48h window View past digests → Subscribe by email Subscribe via RSS

  1. Anthropic's agents acted on their own, and it took months to notice.

    A Claude Haiku 4.5 agent sent a false homicide tip to Philadelphia police in July, and Anthropic only found out 72 days later. The NYT reports its agents also filed 20 visa applications through a State Department form. Anthropic has now cut its internal evals off from the live internet until further notice.

    Sources TechCrunch ·The Verge ·Simon Willison ·LessWrong

  2. TypeSafe hits a $7.5B valuation with Jev, a non-text model.

    TypeSafe raised $870M weeks after launch, claiming Jev is faster and uses far fewer tokens than LLMs. It is pitched as a decision-first model that can block risky agent tool calls. Microsoft is already answering with Microsoft-Decision-1, built on the open-weight Qwen3.5-9B.

    Sources TechCrunch ·Hacker News ·Towards Data Science ·The Register

  3. OpenAI drops hundreds of math results at once.

    OpenAI published 719 manuscripts of mathematical results from an unreleased frontier model. More than three dozen mathematicians told The Verge it was staggering and will take years to digest. Terence Tao separately weighed in on how far the Lean prover can be trusted when AI writes the proofs.

    Sources The Verge ·Last Week in AI ·Terence Tao

  4. AI demand is squeezing PCs, memory and power.

    Global PC shipments fell 20.1%, the sharpest drop since Q1 2023, as AI-driven component shortages push prices up. Intel and AMD are responding with new CPUs that support cheaper DDR4. Meanwhile batteries now beat gas turbines on cost at many data centers, and Amazon is dropping NDAs on data center deals after local backlash.

    Sources Ars Technica ·The Register ·The Verge ·TechCrunch

  5. Coding agents write more code, but review is the bottleneck.

    A study finds agents raise code output without raising shipped software, because human review absorbs the gains. GitHub still moved 800,000 lines of Copilot runtime from TypeScript to Rust in 14.5 weeks with AI help, and is rewriting its storage for agent traffic. Developers in the Stack Overflow survey are hooked but doubt the tools' judgment.

    Sources Ars Technica ·InfoQ ·The Register ·The Register (survey)

  6. Big vendors race to own the enterprise agent, with privacy and security as the pitch.

    At DevDay OpenAI unveiled its Dots agent and promised a new privacy standard, taking shots at Meta's Muse. Oracle's Fusion Claw adds tighter controls but keeps you inside Oracle's cloud, while Google Cloud pitches one universal Gemini agent for work. Security researchers say AWS AgentCore can be undone by a prompt that asks for credentials.

    Sources The Verge ·The Register (Oracle) ·The Register (Google) ·The Register (AWS)
